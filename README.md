# Elias-Fano Encoding Animation

An animated, step-by-step visualization of Elias-Fano encoding built with
React, Framer Motion, and SVG.

## Running

```sh
cd anim
npm install
npm run dev
```

Then open http://localhost:5173/ in your browser.
